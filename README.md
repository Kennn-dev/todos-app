# The BEST todos app

Học tư duy lập trình bằng cách phát triển một todo app qua các requirement "ngẫu nhiên".

## Stack

React + Vite + TypeScript, dữ liệu lưu ở localStorage.

## Chạy

```bash
npm install
npm run dev
```

## Nhật ký requirement

| Vòng | Requirement | Ghi chú |
| --- | --- | --- |
| 1 | Thêm / xem / toggle hoàn thành / xoá todo | |
